# Beans & Bullets prototype

> Prototype for a future indie game.


It would be a top-down multiplayer 2d shooter with fun movement mechanics.

A mix of CS, Valorant, and Call of Duty.

This is a prototype that will test a bunch of different things for movement
and rendering, so I can get a feel for the game, and see if it would be good
to invest my time long term.
